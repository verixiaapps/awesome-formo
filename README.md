## Examples

> A collection of example applications demonstrating Formo Analytics SDK integrations across different frameworks and platforms. See the full [examples repository](https://github.com/getformo/examples).

### Web Frameworks

- [React](https://github.com/getformo/examples/tree/main/with-react) - Create React App integration.
- [Next.js App Router](https://github.com/getformo/examples/tree/main/with-next-app-router) - Next.js App Router integration.
- [Next.js Pages Router](https://github.com/getformo/examples/tree/main/with-next-page-router) - Next.js Pages Router integration.

### Wallet Integrations

- [Privy](https://github.com/getformo/examples/tree/main/with-privy) - Privy embedded wallets.
- [Dynamic](https://github.com/getformo/examples/tree/main/with-dynamic) - Dynamic.xyz wallet.
- [Reown](https://github.com/getformo/examples/tree/main/with-reown) - Reown AppKit / WalletConnect.
- [Porto](https://github.com/getformo/examples/tree/main/with-porto) - Porto wallet.
- [MetaMask](https://github.com/getformo/examples/tree/main/with-metamask) - MetaMask integration.
- [Thirdweb](https://github.com/getformo/examples/tree/main/with-thirdweb) - Thirdweb integration.
- [Turnkey](https://github.com/getformo/examples/tree/main/with-turnkey) - Turnkey integration.
- [Web3-Onboard](https://github.com/getformo/examples/tree/main/with-web3-onboard) - Web3-Onboard integration.

### Blockchain Platforms

## Tools

- [ERC-8021 Validator](https://formo.so/erc-8021-validator) - Validate ERC-8021 Builder Code attribution in transaction calldata.
- [Wei Converter & Gwei Calculator](https://formo.so/wei-converter) - Convert between Wei, Gwei, and Ether units.
- [UTM Builder](https://formo.so/utm-generator) - Free UTM link generator for Web3 campaign tracking.
- [ROI Calculator](https://formo.so/roi-calculator) - Web3 marketing ROI calculator with onchain attribution.
- [Churn Rate Calculator](https://formo.so/churn-calculator) - Churn rate calculator for onchain apps.
- [Web3 Data Tools Directory](https://formo.so/web3-data-tools) - Curated directory of top data and analytics tools for onchain teams.
